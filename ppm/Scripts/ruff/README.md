# Notice

This directory contains **raw, binary** versions of ruff (Vendored).

However, for windows:

> You'll need a UCRT runtime installed (Windows 10 and Windows Server 2016 native shipped)
and `Windows Update` on older systems to install it.

and on Linux:

> You'll need a system WITH `glibc 2.17`. So older systems, or musl-based systems WILL FAIL to execute.
